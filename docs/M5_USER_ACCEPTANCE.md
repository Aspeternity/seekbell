## 本机运行命令

在正式WSL目录执行；不要在D盘交接副本操作：

```bash
# 首次配置，已有文件时不要覆盖。
test -f deploy/.env.acceptance || cp deploy/acceptance.env.example deploy/.env.acceptance
docker compose --env-file deploy/.env.acceptance \
  -f deploy/compose.yaml -f deploy/compose.acceptance.yaml up --no-color
```

当前从聊天启动的前台Compose会话保持SeekBell-Dev活动；WSL仅剩systemd服务时可能退出，因此这里使用前台up并保留终端。若会话关闭，重新执行上述命令即可，已有验收卷会保留。

Windows进入：`wsl.exe -d SeekBell-Dev --cd /home/dev/projects/seekbell`。停止验收服务而保留账号/任务：

```bash
docker compose --env-file deploy/.env.acceptance \
  -f deploy/compose.yaml -f deploy/compose.acceptance.yaml stop seekbell
```

不执行down -v、全局prune或清空卷。若要重置需另行明确选择。恢复也使用不同项目/新空卷，详见DEPLOYMENT。
