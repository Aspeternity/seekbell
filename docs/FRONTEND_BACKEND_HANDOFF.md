6. 浏览器备份不等于生产数据库备份。正式备份/恢复与部署验证按M4推进。

## 建议下一阶段顺序

先完成一个可验收的小闭环：真实首次创建管理员/登录 → 从内置目录添加网站 → 创建任务 → 后端持久化，刷新及重新登录后仍可读取。

实施前核对数据模型和API契约，复用现有后端服务；完成会话、访问控制及必要认证防护后，再接网站/任务/设置。通知配置、内容/命中/投递查询、概览统计、后端规则试算依次接入，逐项移除正式入口中的假数据和假操作。

再接采集与投递生命周期、暂停/恢复及规格内的重试/手动操作。任务运行由服务端负责，关闭浏览器不停止监控。采集、解析、规则、队列和渠道维持分层。

最终将管理界面接入正式前端入口，Vite构建由FastAPI提供静态资源及API，维持既定单容器模块化单体；保留独立模拟入口供演示及测试。不要另起微服务或更换技术栈。

每个独立改动做针对性自动验证并更新PROJECT_STATE；真实RSS/通知、生产部署与发布需按既有授权边界另行进行。
