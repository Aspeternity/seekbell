当前设置已具备时区、告警、历史清理、账号修改及加密备份等基础能力。主要问题是分类和入口没有随功能增加调整，多个页面重复编辑相同设置，保存、失败重试与恢复操作不一致。应先修复草稿丢失和入口不可达，再重新分组，最后增加数据维护与安全方面的能力。

## 分类和页面方案

建议系统设置采用七个清晰分类。桌面将现有占用290px的说明栏调整为有用的分类导航与宽度受控的内容区；说明放到相关字段或折叠帮助中。平板和手机提供可见的分类选择，完整列出当前分类与所有入口。

| 分类 | 放置内容 | 页面安排 |
| --- | --- | --- |
| 通用 | 工作空间名称、说明、显示时区 | 两个短分区，统一保存；时间示例就近显示。 |
| 界面与概览 | 概览模块显隐、排序、恢复默认 | 保留现有可拖动、键盘排序与草稿行为；外观偏好可后续加入。 |
| 系统告警 | 故障与恢复开关、接收目标、有效目标提示 | 设置与事件记录分别呈现，当前故障和历史有明确入口。 |
| 历史与存储 | 保留天数、清理范围、最近/下次清理、清理数量 | 既有清理状态直接进入本分类；占用和影响预估另补后端数据。 |
| 备份与恢复 | 生成下载、文件验证、独立恢复副本、维护说明 | 下载和恢复各自完整操作区，恢复步骤分开展示，状态可重新读取。 |
| 账户与安全 | 管理员用户名、密码 | 改用户名与改密码语义清楚，敏感操作保留当前密码验证；后续加入会话管理。 |
| 关于与诊断 | 应用/代码/数据库版本、支持网站、运行状态、维护帮助 | 主视图使用人能理解的状态；技术代码可展开及复制。 |

每个设置只保留一处编辑器，其他入口定位到它；保留旧/settings/display、retention、alerts及overview-modules深链接兼容。常规表单各自保存，有修改时显示就近或吸底的“未保存/放弃/保存”操作区，不把备份、账号修改与普通偏好合为一次保存。加载沿用200ms延迟反馈，读取失败不显示成保存中。

需要收敛的是信息架构和重复表单，不必重做整站视觉、导航或通知业务。已保存的配置及默认行为均迁移保留；先前UI_DESIGN中的四标签等约定，待用户批准新方案后统一回写。

## 值得新增的设置与能力

以下区分真正缺失的能力和已有功能的入口改善。清理状态、告警记录、时区管理、概览排序已经存在，应整理入口而非重新实现。

| 顺序 | 新增项 | 用途与实施边界 |
| --- | --- | --- |
| 优先补充 | 数据占用和清理影响预览 | 显示数据库/备份占用、可用空间；缩短保留期前预估受影响历史。需要新增只读统计接口，不能把行数估算直接当成可释放磁盘空间。 |
| 优先补充 | 备份生成与验证记录 | 记录生成时间、应用/数据库版本、大小、验证结果；文件名带时间，副本展示创建信息。浏览器实际保存文件无法由服务端保证，文案应区分已生成、已交给浏览器和已验证。 |
| 优先补充 | 当前会话和退出其他会话 | 现有会话固定12小时，修改管理员会撤销其他会话，但没有单独管理入口。先提供当前会话到期信息和撤销其他会话；浏览器/设备名称需有真实元数据后再显示。 |
| 优先补充 | 复制诊断摘要和帮助入口 | 汇总版本、运行状态、失败原因、检查时间；只复制明确白名单字段，便于反馈问题。维护说明、升级与备份文档直接可达。 |
| 后续独立阶段 | 定时加密备份、保留份数和备份失败告警 | 需要明确落盘位置、口令/密钥保管、空间上限与执行失败记录。当前只有人工导出，不能仅加一个开关就宣称完整自动备份。 |
| 按需求选择 | 跟随系统主题、阅读密度/字号 | 这是界面偏好，优先级低于数据维护和保存问题；应明确按浏览器保存还是全工作空间共享，避免一台设备改变另一台阅读体验。 |

网站采集间隔、热榜刷新间隔继续归属对应网站；渠道凭据与消息样式归属通知目标；匹配条件归属任务。系统设置可提供定位入口，不再复制编辑字段。端口、数据目录、可信代理等启动参数可在诊断中展示必要信息，继续遵循部署配置；网页不接入Docker socket或在线切换数据卷。

全局静默时段、通知合并/每日摘要、任意模板、单击清空去重账本等会改变通知或数据语义，当前没有足够需求依据纳入本轮。应用本身停机时不能保证发出自我故障告警，诊断与备份告警不能被描述为外部可用性监控的替代品。

## 建议实施顺序和验收

第一阶段修复已复现的草稿丢失、平板入口消失、错误定位问题，并整理错误文案、版本信息、恢复表单及维护链接。这批工作以界面正确性为主，不改采集、通知、清理规则。

第二阶段按新分类整合重复编辑器，做到独立加载/保存、完整草稿保护、明确保存结果；补工作空间并发保护，统一时区选择和告警有效目标说明。涉及版本字段等持久结构时另做迁移验证。

第三阶段按用户选定范围加入存储统计、备份记录、会话管理、诊断摘要。定时备份单独设计后交付，避免同时叠加大量新设置。

验收至少包括：320/390/768/900/1440px所有分类可达；错误提交定位到对应字段；所有重新读取/重试/离开路径保留或明确放弃草稿；一个分类加载失败不锁住其他分类；并发修改不静默覆盖；备份与恢复可各自独立操作；模拟故障不发真实通知；旧链接和既有保存配置继续有效。
