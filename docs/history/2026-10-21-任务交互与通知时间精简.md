# 任务交互与通知时间精简

日期：2026-10-21，M5用户实测修正。基于codex/ui-content-readability的9810ba0；本记录/状态与代码同提交。用户先要求方案审批，随后明确同意四项、但铅笔编辑按钮先保留。本轮严格按此范围实现，未删除编辑按钮，未发布/合并/部署或真实发送。

## 已确认并实现

1. Telegram时间仍按保存时区转换，只显示YYYY-MM-DD HH:mm:ss，不附IANA名称。format_timestamp/post_time/render用显式show_timezone参数控制后缀，Telegram普通/测试/手动重发/告警均关闭；标题、任务、摘要内容不做全局字符串替换，Bark/SMTP仍附时区，Webhook与UTC存储不变。
2. TaskList共享生产/演示统计、筛选、行状态统一全部任务/已启用/已暂停，去掉运行中/已启用配置/配置已启用混用。任务行改为独立网格列：左侧信息弹性，状态104px、开关29px，右侧操作按内容独立；演示统计列按原断点隐藏。手机状态与右侧操作位于卡片第二行，不互相挤压。状态文案变化不会改变开关坐标，已启用只代表任务开关，不宣称来源/渠道一定正常。
3. 主菜单为概览→监控网站→通知管理→监控任务→内容与命中，系统设置、账号和退出留底部，按网站/通知目标/任务的配置依赖排序。
4. 点击任务行信息/空白进入该任务配置，悬停/焦点轻微高亮；标题仍提供键盘入口。行处理跳过开关、编辑、复制、删除及操作容器，选中文本时不跳转，不重复触发路由。铅笔按钮原样保留；复制/删除语义和未保存离开保护沿用既有实现。

SPEC/UI_DESIGN/ARCHITECTURE同步确认范围；不改采集、启停、去重或任务复制/删除业务逻辑，无迁移/依赖变化。
