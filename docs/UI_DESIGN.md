# SeekBell 管理界面设计规范 · v0.1 草案

范围：概览、任务编辑及响应式适配。此文是本轮已实现原型的设计说明，尚待用户验收，不等同全部六页的最终规范。

## 方向

“留意你关心的”：安静、克制、可扫读。暖橙作为行动色，偏冷的浅灰页面承托白色面板，石墨色文字建立层次；淡绿只表达正常与启用。品牌使用原创线性铃铛与 seekbell. 字标，不使用图像背景和装饰插画。信息密集区域依靠留白、细边框、字号与排版分组。

概览顺序：当前状态 → 四项关键数字 → 命中趋势与采集健康 → 任务操作 → 最近命中。编辑顺序：基本信息 → 匹配规则 → 通知目标；规则说明与测试作为右侧辅助区。移动端保留同样逻辑，辅助区置于表单后，可通过“试匹配”直接跳转。

## 组件及状态

- 主按钮：橙底白字，整页主行动集中在“新建任务”或底部“保存任务”。次按钮为白底细边框。悬停、键盘焦点、禁用状态分别可见。
- 状态：正常/启用使用绿色；重试与信息不足使用琥珀色；确定不匹配使用浅玫瑰色。每项同时给出文字或图标，不只依赖颜色。
- 表格/任务卡：任务名称是主要编辑入口，尾部箭头为明确入口。开关立即作用于本地模拟状态；筛选、搜索无匹配时显示可恢复的空态。
- 标签输入：回车/英文逗号/失焦添加，精确重复去重，删除按钮具有可读名称。最多 64 项，每项 200 字符；短语空格不切分。
- 条件组：组内标注 AND，组间以“或者”连接。全局排除单独呈现，并明示优先否决。未设置任何筛选时显示全部新帖警告。
- 单选/多选：匹配范围为单选；版块与通知目标可多选。目标选择使用整行可点的卡片，保留原生复选框。
- 校验：保存时集中列出问题并移动焦点；字段同时有错误状态。未保存离开使用原生对话框，提供“继续编辑”与“放弃修改并离开”。
- 试匹配：结果带结论与原因；任何相关输入变化都会清掉旧结果。历史样本明确显示样本数量与时间范围，不把试算当成真实发送。
- 固定保存栏：展示保存后的启用状态与本地持久化边界。底部留白避免遮住最后一项内容。
- 图表：橙色折线与轻填充，只表示命中次数；24 小时与 7 天切换同步更新相应统计。保留文字总数、SVG 描述与每个点的提示。

## 响应式

|宽度|布局|
|---|---|
|大于 1200px|固定左导航；四列统计；趋势/来源双列；编辑/辅助双列|
|1001–1200px|收窄导航与留边；减少装饰小图，目标卡片改一列|
|761–1000px|双列统计；来源独立行；编辑单列，辅助区双列|
|不大于 760px|抽屉导航；双列统计；任务表格转换卡片；单列编辑；固定底栏|
|320–370px|进一步压缩留边、章节序号与次要标记，保持表单不横向滚动|

手机抽屉使用遮罩与背景 inert，支持 Escape 关闭并恢复触发按钮焦点；Tab 保留在抽屉内。页面支持跳过导航、原生表单标签、aria-pressed/checked、结果状态播报和 reduced-motion。实际手机 Safari/安卓浏览器与屏幕阅读器验收仍待进行。

## 后续接入原则

用户确认后才扩展监控网站、内容与命中、通知管理、系统设置和初始化/登录。正式接入时保留组件外观，替换数据提供与提交逻辑：规则测试由后端统一判断，目标来自受保护 API，凭据不回传，采集频率为来源级设置，固定统计改为带查询范围的真实统计。不得把原型中的“运行正常”、示例目标或本地任务当成真实系统状态。
