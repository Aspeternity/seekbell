## 设计方向与信息架构

“留意你关心的”：安静、克制、可扫读。暖橙用于主要行动，浅灰底承托白色面板，石墨文字建立层次，淡绿表达正常与启用。原创线性铃铛和 seekbell. 字标；不依赖照片、远程字体或装饰插画。信息密集区域使用留白、细边框和排版分组。

固定主导航：概览、监控网站、通知管理、监控任务、内容与命中；系统设置与账号/退出固定在底部。网站→通知目标→任务→查看内容按配置依赖排列。通知管理分通知目标/投递记录/目标测试；系统设置分通用、界面与概览、系统告警、历史与存储、备份与恢复、账户与安全、关于与诊断七类。列表到详情/编辑保留明确返回入口。新增目标和任务是实际表单，不使用空白占位页。登录/初始化使用独立双区布局，左侧品牌与能力摘要，右侧表单。工作空间卡片与左下账号仅展示信息，偏好和管理员统一从系统设置进入；顶栏移除账号头像。账号行右侧独立门形箭头按钮用于退出，提供退出登录名称/悬停提示及提交中状态；有未保存编辑时确认放弃，成功注销服务端会话后返回登录页，失败保留当前编辑并提示重试。概览采集卡按上节单站/多站规则呈现；命中内容详情与投递记录等上下文跳转保留。

## 组件规则

2026-10-23实测修正：通知管理的通知目标/投递记录/手动重发/测试记录均通过真实标签点击切换，保持选中状态，支持刷新与浏览器前进后退。概览监控任务与任务列表一致，信息格及空白区域点击进入该任务配置；名称与编辑按钮保留键盘入口，开关/状态区和独立操作不触发行编辑，拖选文字与修饰键点击不跳转。

文字输入与原生下拉使用控件自身的细边框及浅阴影表示焦点，避免叠加粗橙色outline。带图标的搜索框由完整外壳统一反馈焦点，内部输入填满可用区域且不单独画框；按钮、链接及复选/单选保留键盘焦点环。路由标题聚焦仍不显示外框，页面布局与既有配色保持。


2026-10-21用户确认：任务页统计/筛选/行状态统一为“全部任务 / 已启用 / 已暂停”，已启用仅表示任务配置开关。状态区及开关定宽、各行对齐，手机固定在卡片底部与操作区并列。点击行信息/空白进入配置，标题保留键盘入口；开关、编辑、复制、删除及各自操作区域独立，不触发行跳转；文本选中不跳转。轻微悬停/聚焦提示。用户明确保留铅笔编辑按钮，不能以入口去重为由移除。

- **按钮与反馈**：主按钮橙底白字，每个流程有清楚的主行动；次按钮白底边框，危险操作使用可辨识文本和确认。忙碌时禁用重复提交。保存/成功动作显示状态提示，错误在当前表单内保留原因。
- **列表与卡片**：标题为详情或编辑入口，辅助行显示规则/渠道/时间；尾部为开关与操作。无筛选结果给出可恢复空态。长文本换行，不迫使手机整页横向滚动。
- **状态**：成功/启用为绿色，重试/信息不足/未知为琥珀色，失败为玫瑰色，取消/停用为中性灰；同时显示文字。未知不写“失败且未送达”，SMTP成功不写“已进收件箱”。
- **表单**：标签固定可见，必填与帮助相邻。渠道字段随类型变化，既有目标不切换渠道。保存校验后展示错误并聚焦；已配置敏感输入不回显。明文SMTP需要显式同意，Webhook响应判断可选JSON或HTTP接受语义。
- **关键词标签**：回车/英文逗号/失焦添加，重复去重；每类最多64项，每项200字符，保留短语空格；删除按钮有可读名称，输入法确认不误触提交。
- **条件组**：组内AND、组间OR；排除优先单独呈现。空条件组不使其他条件失效；无任何筛选时明确提示全部新帖。匹配范围单选，版块/通知目标多选。
- **规则试算**：自然语言说明实时更新，结果同时包含三值结论和原因。规则或样本变更后清除旧结论；试算不产生投递。
- **保存栏**：编辑页固定底栏，提供返回/取消/保存和本地保存说明。页面预留底部空间，避免挡住字段。未保存离开、浏览器后退与刷新分别使用应用确认或浏览器原生提示。
- **对话框**：原生dialog，动作明确、可取消。删除任务提示保留历史；删除通知目标仅列出删除后没有通知目标的任务（详见下文）；手动重发未知结果提示重复可能。确认前不改变数据。
- **图表**：橙色折线及轻填充，保留文字总数、SVG描述及点提示。24小时/7天同步切换统计快照。来源健康是独立信息，不把历史图当实时采集。
- **详情与快照**：内容摘要默认文本，不执行HTML。任务删除仍显示历史名称及“已删除”；关联记录有返回与交叉入口。缺失数据与不存在路径均有明确恢复入口。
- **备份**：网页下载加密备份，上传后验证并生成独立恢复副本；不覆盖运行中的数据卷。正式切换通过宿主机维护命令执行。

## 正式数据与交互边界

页面通过真实API读取和提交，SQLite为配置与历史权威；跨页面、刷新、重启及重新登录保留服务端已保存数据。复制任务默认暂停，历史快照不随重命名或删除重写。目标停用取消尚未发送的重试，恢复不补发；独立测试与手动重发明确确认、单独留证。来源频率共享，不放到单任务里。

初始化创建唯一服务端管理员，使用密码哈希、HttpOnly会话、CSRF/Origin和限速保护。敏感连接字段只写入服务端加密配置，读取不回显；前端浏览器校验改善体验，服务端仍独立验证。规则试匹配与历史试算统一后端RuleEngine，无浏览器模拟执行分支。

后台采集、重试、告警、保留策略由服务端执行；真实历史和统计明确时间范围及分页。测试直接运行正式界面配临时数据库和合成服务，不提供独立演示产品入口。消息预览中的固定示例用于解释输出格式，不写入正式内容或发送。

## 网站管理扩展规范（v0.4）

区分“可用适配器”和“已添加网站”：列表只展示用户添加的实例，内置库只展示已实现适配器。初始为带三步引导的空态，不自动预置NodeSeek，也不显示虚假运行数字。不提供载入示例工作台的产品入口。平台品牌文案使用“关注的网站”，NodeSeek仅在实际目录、配置、示例或历史记录中出现。
