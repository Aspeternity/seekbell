# SeekBell 管理界面设计规范 · v0.2

范围：六个管理模块、详情/编辑页、初始化/登录、桌面和移动布局。首轮视觉已获用户确认；本规范对应完整前端模拟数据版的实际实现。运行与业务边界见 [UI_PROTOTYPE](UI_PROTOTYPE.md)。

## 设计方向与信息架构

“留意你关心的”：安静、克制、可扫读。暖橙用于主要行动，浅灰底承托白色面板，石墨文字建立层次，淡绿表达正常与启用。原创线性铃铛和 seekbell. 字标；不依赖照片、远程字体或装饰插画。信息密集区域使用留白、细边框和排版分组。

固定主导航：概览、监控网站、监控任务、内容与命中、通知管理、系统设置。通知管理分通知目标/投递记录/目标测试；系统设置分偏好/管理员/备份/关于。列表到详情/编辑保留明确返回入口。新增目标和任务是实际表单，不使用空白占位页。登录/初始化使用独立双区布局，左侧品牌与能力摘要，右侧表单。

|页面|信息优先级|主要行动|
|---|---|---|
|概览|当前运行状态 → 四项指标 → 趋势与来源 → 任务 → 最近命中|新建任务|
|网站|来源状态与能力 → 共享频率 → 模拟连接结果|保存设置|
|任务列表|搜索/状态 → 任务规则摘要 → 启停与更多操作|新建任务|
|任务编辑|基本信息 → 条件组/排除/范围 → 目标；侧栏规则说明/试匹配|保存任务|
|内容|筛选 → 帖子与命中状态 → 分页；详情摘要/原因/投递|打开详情|
|通知|目标卡与渠道 → 编辑/独立测试；记录按状态筛选|新建目标|
|目标编辑|名称/启用 → 渠道连接参数 → 消息摘要；侧栏预览|保存目标|
|设置|明确分栏；备份导入先校验摘要，再确认替换|保存设置|
|登录/初始化|用途说明 → 用户名/密码/错误 → 主行动|登录/创建管理员|

## 组件规则

- **按钮与反馈**：主按钮橙底白字，每个流程有清楚的主行动；次按钮白底边框，危险操作使用可辨识文本和确认。忙碌时禁用重复提交。保存/成功动作显示状态提示，错误在当前表单内保留原因。
- **列表与卡片**：标题为详情或编辑入口，辅助行显示规则/渠道/时间；尾部为开关与操作。无筛选结果给出可恢复空态。长文本换行，不迫使手机整页横向滚动。
- **状态**：成功/启用为绿色，重试/信息不足/未知为琥珀色，失败为玫瑰色，取消/停用为中性灰；同时显示文字。未知不写“失败且未送达”，SMTP成功不写“已进收件箱”。
- **表单**：标签固定可见，必填与帮助相邻。渠道字段随类型变化，既有目标不切换渠道。保存校验后展示错误并聚焦；已配置敏感输入不回显。明文SMTP需要显式同意，Webhook响应判断可选JSON或HTTP接受语义。
- **关键词标签**：回车/英文逗号/失焦添加，重复去重；每类最多64项，每项200字符，保留短语空格；删除按钮有可读名称，输入法确认不误触提交。
- **条件组**：组内AND、组间OR；排除优先单独呈现。空条件组不使其他条件失效；无任何筛选时明确提示全部新帖。匹配范围单选，版块/通知目标多选。
- **规则试算**：自然语言说明实时更新，结果同时包含三值结论和原因。规则或样本变更后清除旧结论；试算不产生投递。
- **保存栏**：编辑页固定底栏，提供返回/取消/保存和本地保存说明。页面预留底部空间，避免挡住字段。未保存离开、浏览器后退与刷新分别使用应用确认或浏览器原生提示。
- **对话框**：原生dialog，动作明确、可取消。删除任务提示保留历史；删除有任务依赖的目标阻止操作；手动重发未知结果提示重复可能。确认前不改变数据。
- **图表**：橙色折线及轻填充，保留文字总数、SVG描述及点提示。24小时/7天同步切换统计快照。来源健康是独立信息，不把历史图当实时采集。
- **详情与快照**：内容摘要默认文本，不执行HTML。任务删除仍显示历史名称及“已删除”；关联记录有返回与交叉入口。缺失数据与不存在路径均有明确恢复入口。
- **备份**：文件选择 → 结构校验 → 记录数量摘要 → 确认恢复。普通配置导出明确不含凭据；演示恢复不冒充生产数据库恢复。

## 响应式与访问方式

|宽度|规则|
|---|---|
|>1200px|固定左导航、四列指标、趋势/来源与编辑/辅助双列|
|1001–1200px|收窄导航与留边，卡片减少列数|
|761–1000px|双列指标、来源独立行、编辑单列、辅助区可双列|
|≤760px|抽屉导航、双列指标、表格转卡片、表单单列、底部保存栏|
|320–370px|减少留边与次要标记，保留标签和完整操作，禁止整页横向滚动|

手机通知卡/记录/设置和内容详情均为单列；工具栏换行，标签页允许自身滚动。登录页收起品牌大区为紧凑顶部，避免首屏被装饰占据。窄高窗口的侧栏可滚动。

支持跳过导航、原生表单label、按钮可读名称、aria-pressed/checked、状态播报、reduced-motion。手机菜单使用背景inert与焦点约束，Escape关闭后恢复触发按钮焦点。路由切换将焦点放到标题但不显示控件式外框；交互控件保留键盘焦点环。颜色不承担唯一状态信息。

自动覆盖Chromium桌面与手机仿真及320–1440布局；尚未完成Safari、手机真机、屏幕阅读器与完整WCAG审计，不能把自动测试当作这些验收。

## 交互状态与模拟边界

共享状态保证列表、详情、概览、目标选择和设置互相一致；同一浏览器刷新后保留。任务复制默认暂停，历史快照不随重命名或删除重写。目标停用取消尚未发送的本地重试，重启不补发；测试与手动重发产生独立记录。来源频率属于共享来源，不放到单任务里。

初始化创建一个浏览器演示账号；退出后管理路径跳登录。账户和密码流程只演示交互。通知连接字段不持久化，普通配置恢复会丢弃未知字段。合成内容无真实原帖链接时明确说明。所有“模拟”标识应保留至真实接入完成，不能让用户误以为正在监听论坛。

## 正式接入约定

后续保持界面与组件，替换store的数据和提交适配；受保护API是业务权威。规则测试统一后端RuleEngine，凭据只写不读，来源频率共享；真实历史与统计有明确时间范围和分页。服务端校验必须独立存在，浏览器校验仅改善输入体验。

真实认证需唯一管理员、密码哈希、会话/CSRF/限速及服务端访问控制，不能沿用演示账号存储。生产备份必须一致性备份数据库并安全封装密钥；恢复先验证并停止后台写入。真实调度/重试/告警/保留策略必须由后端实现。原型备注字段的正式存储映射需单独确认。
